# DocumentMarketplace

An archived prototype of the original native iOS document-marketplace concept. It is a Swift/Xcode project backed by Firebase and includes Cloud Functions.

## Run locally

1. Install CocoaPods dependencies with \`pod install\`.
2. Open \`DocumentMarketplace.xcworkspace\` in Xcode.
3. Select an iOS simulator and run the app.

Active DocumentXchange development now lives in the separate \`documentxchange\` repository.
